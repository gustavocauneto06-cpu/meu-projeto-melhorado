HTML


HTML5 é a versão moderna da linguagem HTML, utilizada para estruturar e organizar o conteúdo de páginas e aplicações web. A sigla HTML significa **HyperText Markup Language**, ou Linguagem de Marcação de Hipertexto. O HTML5 trouxe melhorias importantes para o desenvolvimento de páginas web, oferecendo novos elementos, recursos e uma estrutura mais organizada para os documentos. O HTML5 é uma das principais tecnologias que formam a base do desenvolvimento web e é utilizado em praticamente todos os tipos de sites e aplicações acessadas por navegadores.

## Para que serve o HTML5?
A principal função do HTML5 é definir a estrutura e o significado do conteúdo de uma página. Por meio dele, é possível organizar títulos, textos, imagens, links, listas, tabelas, formulários, vídeos, áudios e diversos outros elementos. O HTML5 também permite criar uma estrutura mais clara e organizada para as páginas, facilitando a interpretação do conteúdo por navegadores, mecanismos de busca e tecnologias assistivas. Ele não é responsável principalmente pela aparência da página. Sua função é estruturar o conteúdo e definir o papel de cada elemento dentro do documento.

## A evolução do HTML:
O HTML passou por diversas mudanças desde sua criação. Com o crescimento da internet, os sites começaram a apresentar conteúdos cada vez mais complexos, e surgiu a necessidade de novos recursos para acompanhar essa evolução. O HTML5 foi desenvolvido para atender melhor às necessidades da web moderna. Ele trouxe novos elementos semânticos, melhorias nos formulários, suporte nativo para conteúdos multimídia e diversos recursos que ajudaram a tornar o desenvolvimento web mais organizado.

## HTML5 e semântica:
Uma das principais características do HTML5 é o uso de elementos semânticos. Semântica significa utilizar cada elemento de acordo com seu significado e finalidade. Em versões mais antigas do HTML, era comum encontrar páginas estruturadas utilizando muitos elementos genéricos. O HTML5 introduziu elementos que permitem representar de maneira mais clara partes específicas de uma página. Entre essas estruturas estão áreas destinadas ao cabeçalho, navegação, conteúdo principal, seções, artigos e rodapé. Essa organização torna o código mais fácil de compreender e ajuda diferentes tecnologias a interpretar a estrutura da página.

## Estrutura de uma página HTML5:
Uma página HTML5 possui uma estrutura organizada que permite ao navegador identificar corretamente o documento. Essa estrutura possui uma área responsável por informações sobre a página e outra destinada ao conteúdo que será apresentado ao usuário. Na parte de informações podem ser definidos elementos como o título da página, configurações de caracteres, informações para mecanismos de busca e recursos externos. A área principal contém o conteúdo que será visualizado pelo usuário. Essa divisão ajuda a manter o documento organizado e facilita sua manutenção.

## Elementos de texto:
O HTML5 possui diferentes elementos destinados à apresentação e organização de textos. Títulos podem ser utilizados para criar uma hierarquia entre os assuntos de uma página, enquanto parágrafos permitem organizar blocos de texto. Essa hierarquia é importante porque facilita a leitura e ajuda usuários e mecanismos de busca a compreenderem quais são os assuntos principais e secundários de uma página. Uma boa organização textual também torna o conteúdo mais agradável para o usuário.

## Links e navegação:
Os links são fundamentais para o funcionamento da web. Eles permitem conectar diferentes páginas, documentos e recursos. Com HTML5, é possível criar sistemas de navegação que permitem ao usuário acessar diferentes partes de um site. Os links podem direcionar para outras páginas do mesmo site, páginas externas, arquivos ou determinadas seções dentro de uma página. Essa capacidade de conectar diferentes conteúdos é uma das características que tornam a web tão interligada.

## Imagens:
O HTML5 permite inserir imagens nas páginas, possibilitando a apresentação de fotografias, ilustrações, logotipos e outros conteúdos visuais. As imagens podem complementar informações textuais e melhorar a experiência do usuário. Entretanto, é importante utilizar descrições alternativas quando necessário. Essas descrições ajudam pessoas que utilizam leitores de tela a compreenderem o conteúdo de uma imagem. Além da acessibilidade, também é importante utilizar imagens de maneira adequada para evitar que a página fique excessivamente pesada.

## Áudio e vídeo:
Uma das melhorias importantes do HTML5 foi o suporte nativo para conteúdos multimídia. Antes da popularização do HTML5, era comum depender de tecnologias externas para reproduzir determinados conteúdos de áudio e vídeo. Com HTML5, os navegadores passaram a oferecer recursos próprios para trabalhar com esses formatos. Isso permite desenvolver páginas que apresentam vídeos, músicas, podcasts e outros conteúdos multimídia de maneira mais integrada.

## Formulários:
Os formulários são utilizados para permitir que o usuário forneça informações para uma aplicação. Eles aparecem em páginas de login, cadastro, contato, pesquisas, compras e muitos outros sistemas. O HTML5 trouxe melhorias importantes para formulários, incluindo novos tipos de campos e recursos de validação. Esses recursos ajudam a garantir que determinadas informações sejam preenchidas corretamente antes que sejam enviadas. Os formulários também podem ser utilizados em conjunto com outras tecnologias para criar sistemas mais completos e interativos.

## HTML5 e acessibilidade:
A acessibilidade é uma característica importante do desenvolvimento web moderno. O objetivo é permitir que o maior número possível de pessoas consiga acessar e utilizar uma página. O HTML5 contribui para isso principalmente por meio de uma estrutura semântica bem definida. Quando os elementos são utilizados corretamente, leitores de tela e outras tecnologias assistivas conseguem compreender melhor a organização do conteúdo. Uma boa estrutura de títulos, textos, links, formulários e imagens pode fazer uma grande diferença na experiência de usuários com diferentes necessidades.

## HTML5 e mecanismos de busca:
Uma estrutura HTML5 bem organizada também pode contribuir para a otimização de páginas para mecanismos de busca. Os mecanismos de busca precisam analisar o conteúdo de uma página para compreender seus assuntos e determinar sua relevância. Uma estrutura semântica, títulos bem organizados, conteúdos relevantes e informações adequadas ajudam os mecanismos de busca a interpretar melhor a página. Por isso, aprender HTML5 corretamente também é importante para quem deseja trabalhar com criação de sites e SEO.

## HTML5 e dispositivos diferentes:
Atualmente, páginas web são acessadas por diversos tipos de dispositivos. Computadores, notebooks, tablets e celulares possuem diferentes tamanhos de tela e características. O HTML5 fornece a estrutura necessária para que o conteúdo possa ser interpretado pelos navegadores desses dispositivos. Entretanto, para adaptar visualmente uma página a diferentes tamanhos de tela, outras tecnologias de desenvolvimento web são utilizadas. O HTML5 fornece a base estrutural, enquanto outras ferramentas podem trabalhar com apresentação e comportamento.

## HTML5 e aplicações web:
O HTML5 não é utilizado apenas para páginas simples. Ele também está presente em aplicações web mais complexas. Sistemas administrativos, lojas virtuais, plataformas de estudo, redes sociais, portais de notícias e diversas outras aplicações utilizam HTML como parte de sua estrutura. Mesmo quando uma aplicação utiliza frameworks modernos, o conhecimento de HTML continua sendo importante. Isso acontece porque compreender a estrutura e os elementos da web ajuda o desenvolvedor a trabalhar melhor com ferramentas mais avançadas.

## Vantagens do HTML5:

O HTML5 trouxe diversas vantagens para o desenvolvimento web.

Entre elas estão:
* Estrutura mais organizada;
* Elementos semânticos;
* Melhor suporte para acessibilidade;
* Recursos multimídia;
* Melhorias nos formulários;
* Maior padronização;
* Melhor integração com navegadores modernos;
* Facilidade para desenvolver páginas estruturadas.

Essas características fizeram do HTML5 uma tecnologia fundamental para a web moderna.

## Por que aprender HTML5?
Aprender HTML5 é um dos primeiros passos para quem deseja entrar na área de desenvolvimento web. Mesmo com a existência de frameworks, bibliotecas e ferramentas modernas, o HTML continua sendo uma das bases da web. Um desenvolvedor que conhece HTML5 consegue compreender melhor como as páginas são estruturadas e como os diferentes elementos se relacionam. Esse conhecimento também facilita o aprendizado de outras tecnologias utilizadas no desenvolvimento front-end.

## Como estudar HTML5?
Uma boa maneira de estudar HTML5 é começar entendendo a estrutura básica de uma página e depois avançar gradualmente para seus diferentes recursos. É importante estudar títulos, textos, links, imagens, listas, tabelas, formulários e elementos semânticos. Depois, o estudante pode aprofundar seus conhecimentos em acessibilidade, multimídia, estrutura de documentos e boas práticas. A prática é fundamental. Criar páginas simples sobre assuntos diferentes ajuda a entender como os elementos podem ser combinados para formar documentos completos. Com o tempo, é possível desenvolver páginas pessoais, portfólios, páginas de produtos, formulários e outros projetos.

## Conclusão.
HTML5 é uma das principais tecnologias responsáveis pela estrutura da web moderna. Ele permite organizar conteúdos e definir o significado dos diferentes elementos presentes em uma página. Sua evolução trouxe recursos importantes para a criação de páginas mais estruturadas, acessíveis e completas, incluindo melhorias em formulários, suporte para conteúdos multimídia e elementos semânticos. Apesar de ser uma tecnologia relativamente simples de começar a estudar, seu conhecimento é fundamental para quem deseja trabalhar com desenvolvimento web. Aprender HTML5 corretamente proporciona uma base sólida para continuar os estudos e compreender outras tecnologias utilizadas na criação de sites e aplicações. Por isso, dominar HTML5 é um dos primeiros passos para quem deseja construir uma carreira no desenvolvimento front-end.












CSS

## O que é CSS?
CSS é uma das principais tecnologias utilizadas no desenvolvimento de páginas e aplicações web. A sigla CSS significa **Cascading Style Sheets**, ou Folhas de Estilo em Cascata. Enquanto o HTML é utilizado principalmente para estruturar o conteúdo de uma página, o CSS é responsável por definir sua aparência e apresentação visual. Com CSS, é possível modificar cores, fontes, tamanhos, espaçamentos, posições, bordas, fundos e diversos outros aspectos de uma página. Por meio dele, uma estrutura HTML simples pode se transformar em uma interface organizada, moderna e agradável para o usuário.

## Para que serve o CSS?
A principal função do CSS é controlar a apresentação visual dos elementos de uma página. Ele permite definir como os conteúdos serão apresentados na tela e como diferentes elementos serão organizados. Entre suas possibilidades estão:
* Alterar cores
* Definir tipos e tamanhos de fontes
* Modificar espaçamentos
* Criar bordas
* Alterar fundos
* Organizar elementos
* Criar layouts
* Adaptar páginas para diferentes telas
* Criar animações e transições
* Controlar o posicionamento dos elementos.

O CSS permite separar a estrutura do conteúdo de sua aparência, tornando os projetos mais organizados e fáceis de manter.

## CSS e HTML:
HTML e CSS são tecnologias diferentes, mas trabalham juntas na construção de páginas web. O HTML é responsável principalmente pela estrutura e pelo conteúdo da página. O CSS trabalha com a apresentação visual desses elementos. Uma maneira simples de imaginar essa relação é pensar em uma casa. O HTML seria responsável pela estrutura da casa, como paredes, portas, janelas e cômodos. O CSS seria responsável pela aparência, como cores, iluminação, decoração, tamanho dos elementos e organização visual. Dessa forma, as duas tecnologias possuem funções diferentes, mas complementares.

## Como o CSS funciona?
O CSS funciona aplicando regras de estilo aos elementos presentes em uma página. Essas regras determinam quais características visuais cada elemento deverá possuir. Um desenvolvedor pode definir que determinado título tenha uma determinada cor, que uma área tenha um tamanho específico ou que um conjunto de elementos fique organizado lado a lado. O navegador interpreta essas regras e apresenta o resultado visual para o usuário. Por isso, aprender CSS envolve entender como os elementos são selecionados, como os estilos são aplicados e como diferentes regras interagem entre si.

## Seletores:
Os seletores são uma parte fundamental do CSS. Eles permitem indicar quais elementos de uma página receberão determinado estilo. É possível selecionar elementos pelo seu tipo, por identificadores, por classes e por diferentes características. Os seletores permitem aplicar estilos tanto a elementos individuais quanto a vários elementos ao mesmo tempo. Compreender os seletores é importante porque eles são utilizados constantemente durante o desenvolvimento de uma interface.

## Cores:
O CSS oferece diversas formas de trabalhar com cores. É possível definir cores para textos, fundos, bordas e diferentes elementos da interface. As cores possuem grande importância no design de uma página porque podem destacar informações, criar hierarquia visual e transmitir diferentes sensações. Por isso, escolher cores adequadas não é apenas uma questão estética. É importante também considerar contraste e legibilidade, principalmente quando o objetivo é criar uma interface acessível.

## Tipografia:
A tipografia também possui grande importância no desenvolvimento visual de uma página. O CSS permite controlar características como tipo de fonte, tamanho, peso, espaçamento e alinhamento dos textos. Uma boa escolha de fontes pode melhorar bastante a leitura e a aparência de uma página. Textos muito pequenos, fontes difíceis de compreender ou combinações inadequadas podem prejudicar a experiência do usuário. Por isso, a tipografia deve ser utilizada de maneira planejada.

## Box Model:
Um dos conceitos mais importantes do CSS é o **Box Model**, ou modelo de caixas. O navegador interpreta os elementos de uma página como caixas que possuem diferentes áreas. Essas áreas envolvem o conteúdo, o espaçamento interno, a borda e o espaçamento externo. Compreender o Box Model é fundamental para controlar corretamente o tamanho e o espaço ocupado pelos elementos. Muitos problemas de layout acontecem justamente porque o desenvolvedor ainda não compreendeu completamente como o modelo de caixas funciona.

## Margem e espaçamento interno:
O CSS permite controlar os espaços ao redor e dentro dos elementos. A margem representa o espaço externo de um elemento, enquanto o espaçamento interno representa a distância entre o conteúdo e os limites do próprio elemento. Esses recursos são fundamentais para criar interfaces organizadas. Sem espaçamento adequado, os elementos podem ficar muito próximos uns dos outros, tornando a página confusa e difícil de ler.

## Bordas e cantos:
O CSS permite adicionar bordas aos elementos e controlar suas características. É possível definir espessura, estilo e aparência das bordas. Também é possível arredondar os cantos dos elementos, criando interfaces mais modernas e suaves. Esses recursos são bastante utilizados em cartões, botões, campos de formulário, menus e outros componentes.

## Fundos:
O CSS permite modificar o fundo de diferentes elementos. É possível utilizar cores, imagens e outros recursos visuais. As imagens de fundo podem ser utilizadas para criar páginas mais interessantes visualmente, como áreas com fotografias, ilustrações ou padrões. Também é possível controlar o tamanho, a posição e o comportamento dessas imagens. Um exemplo bastante utilizado é manter uma imagem de fundo fixa enquanto o conteúdo da página é movimentado.

## Posicionamento:
O CSS possui diferentes formas de controlar a posição dos elementos. Isso permite colocar elementos em diferentes partes da página e criar layouts mais complexos. O posicionamento pode ser utilizado para criar menus, elementos sobrepostos, caixas flutuantes, cabeçalhos e diversas outras estruturas. Entretanto, é importante compreender cada tipo de posicionamento para evitar problemas de organização e responsividade.

## Flexbox:
Flexbox é uma das ferramentas mais importantes para criação de layouts utilizando CSS. Ele facilita a organização dos elementos dentro de um determinado espaço. Com Flexbox, é possível controlar o alinhamento, a direção, o espaçamento e a distribuição dos elementos. Ele é muito utilizado em menus, cabeçalhos, botões, cartões, formulários e diversas outras partes de uma interface. Aprender Flexbox é praticamente indispensável para quem deseja desenvolver páginas modernas.

## CSS Grid:
CSS Grid é outra ferramenta importante para criação de layouts. Enquanto o Flexbox é muito utilizado para organizar elementos em uma dimensão, o Grid permite trabalhar de maneira mais eficiente com linhas e colunas. Ele é bastante útil para criar estruturas como galerias, páginas com vários cartões, painéis administrativos e outros layouts mais complexos. Flexbox e Grid podem ser utilizados juntos dependendo da necessidade do projeto.

## Responsividade:
Um dos conceitos mais importantes do CSS moderno é a responsividade. Atualmente, uma página pode ser acessada em monitores grandes, notebooks, tablets e celulares. Cada dispositivo possui diferentes dimensões de tela. O CSS permite adaptar o layout para diferentes tamanhos de tela, fazendo com que os elementos sejam reorganizados conforme necessário. Uma página responsiva oferece uma experiência melhor para os usuários, independentemente do dispositivo utilizado.

## Media Queries:
As Media Queries são um recurso utilizado para aplicar estilos diferentes dependendo das características do dispositivo ou do tamanho da tela. Elas são muito importantes para desenvolver páginas responsivas. Por meio delas, um desenvolvedor pode alterar tamanhos, posições, espaçamentos e organização dos elementos quando a página é acessada em telas menores. Isso permite criar layouts que se adaptam às diferentes necessidades dos usuários.

## Transições e animações:
O CSS também permite criar transições e animações. As transições podem deixar determinadas mudanças visuais mais suaves. Por exemplo, quando o usuário passa o mouse sobre um botão, a mudança de cor pode acontecer gradualmente em vez de ocorrer instantaneamente. As animações permitem criar movimentos e efeitos visuais mais elaborados. Esses recursos podem melhorar a experiência do usuário quando utilizados com equilíbrio.

## Pseudo-classes e interações: O CSS também possui recursos que permitem alterar a aparência de elementos de acordo com determinadas situações. Isso pode ser utilizado para modificar a aparência de botões quando o usuário passa o mouse sobre eles, quando um campo está selecionado ou quando determinado elemento possui uma condição específica. Esses recursos ajudam a criar interfaces mais interativas sem precisar utilizar programação para cada alteração visual.

## Organização do CSS: À medida que um projeto cresce, a organização do CSS se torna cada vez mais importante. Um arquivo pequeno pode ser fácil de entender, mas projetos maiores podem possuir centenas ou até milhares de regras de estilo. Por isso, é importante utilizar nomes claros, organizar os estilos por componentes ou seções e evitar repetições desnecessárias. Um CSS bem organizado facilita a manutenção e permite encontrar problemas com mais facilidade.

## CSS e acessibilidade:
O CSS também possui relação com acessibilidade. Escolher cores com contraste adequado, utilizar tamanhos de texto apropriados e evitar elementos que dificultem a leitura são algumas práticas importantes. Uma interface visualmente bonita não significa necessariamente que seja acessível. Por isso, o desenvolvedor deve considerar diferentes tipos de usuários ao criar seus estilos.

## CSS e desempenho: A quantidade e a organização dos estilos também podem influenciar o desempenho de uma página. Projetos muito grandes e desorganizados podem carregar recursos desnecessários e dificultar a manutenção. Por isso, é importante manter os arquivos organizados e utilizar somente os estilos necessários. Uma boa estrutura de CSS contribui tanto para o desenvolvimento quanto para a manutenção da aplicação.

## Frameworks e ferramentas relacionadas ao CSS:
Existem diversas ferramentas que podem auxiliar no desenvolvimento de interfaces. Algumas fornecem componentes prontos, sistemas de estilos e recursos que aceleram o desenvolvimento. Entre as ferramentas conhecidas estão Bootstrap, Tailwind CSS e outras soluções utilizadas no mercado. Apesar disso, compreender CSS puro continua sendo extremamente importante. Quando o desenvolvedor entende os fundamentos, consegue utilizar frameworks e bibliotecas com muito mais facilidade e compreender melhor o que está acontecendo por trás dos componentes.

## Como aprender CSS?:
Uma boa maneira de aprender CSS é começar pelos conceitos fundamentais. Primeiro, é importante entender seletores, propriedades, cores, fontes e o modelo de caixas. Depois, o estudante pode avançar para posicionamento, Flexbox, Grid e responsividade. Após dominar esses conceitos, pode estudar transições, animações, organização de projetos e técnicas mais avançadas. A prática é essencial. Criar páginas diferentes permite experimentar layouts, cores, fontes e diferentes formas de organização.

## Projetos para praticar:
Existem diversos projetos que podem ser utilizados para praticar CSS. Uma pessoa que está começando pode criar:
* Página pessoal
* Portfólio
* Cartão de perfil
* Landing page
* Página de login
* Página de produtos
* Galeria de imagens
* Menu de navegação
* Dashboard
* Página responsiva para celular.

Esses projetos ajudam a desenvolver a capacidade de transformar uma estrutura HTML em uma interface visual completa.

## Conclusão:
CSS é uma tecnologia fundamental para o desenvolvimento web e possui um papel essencial na criação da aparência das páginas. Por meio dele, é possível controlar cores, fontes, espaçamentos, tamanhos, posicionamento, fundos, bordas e layouts. Além disso, recursos como Flexbox, Grid, responsividade, transições e animações permitem criar interfaces modernas e adaptáveis. Aprender CSS vai muito além de decorar propriedades. É necessário compreender como os elementos se comportam, como os layouts são construídos e como diferentes regras interagem. Uma boa base em CSS permite desenvolver páginas mais organizadas, bonitas, responsivas e acessíveis. Depois de dominar seus fundamentos, o desenvolvedor pode avançar para ferramentas e frameworks que facilitam a criação de projetos maiores. Por isso, aprender CSS é uma etapa fundamental para qualquer pessoa que deseja trabalhar com desenvolvimento front-end e criação de aplicações web.












Java Script

O JavaScript (JS) é uma linguagem de programação utilizada principalmente para adicionar interatividade e funcionalidades às páginas e aplicações web.
Enquanto o HTML é responsável pela estrutura da página e o CSS pela aparência e estilização, o JavaScript é responsável pelo comportamento da página.
### Para que serve o JavaScript?
Com JavaScript, podemos fazer uma página:
* Responder ao clique de botões;
* Alterar textos e elementos da página;
* Criar menus e formulários interativos;
* Validar informações preenchidas pelo usuário;
* Criar animações;
* Fazer cálculos;
* Trabalhar com dados;
* Consumir APIs;
* Criar aplicações web completas;
* Desenvolver sistemas e até aplicações para outras plataformas.

### HTML + CSS + JavaScript Podemos pensar nos três dessa forma:
**HTML → estrutura**
Define o que existe na página.

**CSS → aparência**
Define como os elementos serão apresentados.

**JavaScript → comportamento**
Define o que acontece quando o usuário interage com a página.

Por exemplo, um botão pode ser criado com HTML, estilizado com CSS e fazer alguma ação quando clicado utilizando JavaScript.
### Como o JavaScript funciona?
O JavaScript é uma linguagem interpretada/executada pelo ambiente em que está rodando. No navegador, ele é executado pelo **motor JavaScript** do próprio navegador.

Um código simples seria:
javascript let nome = "Gustavo";
console.log("Olá, " + nome);
Nesse exemplo, criamos uma variável chamada `nome` e armazenamos o texto `"Gustavo"` nela.
Depois, usamos console.log()` para mostrar uma mensagem no console.
### Váriaveis
As variáveis são utilizadas para armazenar informações que podem ser utilizadas durante a execução do programa.
As formas mais comuns são:
javascript
let nome = "Gustavo";
const idade = 26;

*let* é utilizado quando o valor pode ser alterado.
*const* é utilizado quando não queremos alterar a variável depois de criada.
Também existe o *var*, mas atualmente *let* e *const* são geralmente preferidos.
### Tipos de dados
JavaScript possui diferentes tipos de dados, como:

###javascript
let nome = "Gustavo"; // String
let idade = 26; // Number
let ativo = true; // Boolean
let valor = null; // Null

Os principais são:
**String:** texto.
**Number:** números inteiros ou decimais.
**Boolean:** verdadeiro ou falso (`true` / `false`).
**Null:** representa a ausência intencional de um valor.
### Condições
As estruturas condicionais permitem que o programa tome decisões.
Exemplo:
###javascript
let idade = 18;
if (idade >= 18) {
console.log("Maior de idade");
} else {
console.log("Menor de idade");
}

Nesse caso, o programa verifica se a idade é maior ou igual a 18.
Se for, executa o primeiro bloco. Caso contrário, executa o `else`.
### Repetições
JavaScript também possui estruturas de repetição, utilizadas quando precisamos executar determinado código várias vezes.
Exemplo:
###javascript
for (let i = 0; i < 5; i++) {
console.log(i);
}

Esse código executa o `console.log()` cinco vezes.
### Funções
As funções são blocos de código criados para realizar determinada tarefa.
Exemplo:
###javascript
function saudacao(nome) {
console.log("Olá, " + nome);
}
saudção("Gustavo");

Nesse exemplo, criamos uma função chamada `saudacao()` que recebe um nome e mostra uma mensagem.
As funções ajudam a **organizar e reutilizar o código**.
### JavaScript e o HTML
Uma das principais características do JavaScript no desenvolvimento web é poder acessar e modificar elementos do HTML.
Por exemplo:
###html
h1 id="titulo">Olá! h1

Podemos utilizar JavaScript para alterar esse texto:
JAVASCRIPT
document.getElementById("titulo").textContent = "Olá, Gustavo!";

Assim, o JavaScript consegue modificar a página enquanto ela está sendo utilizada.
### Eventos
JavaScript também trabalha com **eventos**, que são ações realizadas pelo usuário ou pelo navegador.
Alguns exemplos:
* Clique do mouse;
* Tecla pressionada;
* Página carregada;
* Movimento do mouse;
* Envio de um formulário.

Exemplo:
###javascript
botao.addEventListener("click", function() {
alert("Botão clicado!");
});
``` Nesse caso, quando o botão for clicado, uma mensagem será exibida.
### JavaScript fora do navegador
Apesar de ser muito conhecido pelo desenvolvimento web, JavaScript não funciona apenas dentro dos navegadores.
Com ambientes como o **Node.js**, é possível utilizar JavaScript no lado do servidor, permitindo desenvolver:
* APIs;
* Back-end;
* Servidores;
* Sistemas;
* Ferramentas de automação.
Por isso, JavaScript pode ser utilizado tanto no **Front-end** quanto no **Back-end**.
### Resumindo
O **JavaScript** é responsável principalmente pela **lógica e interatividade** das aplicações.

**HTML → estrutura**
**CSS → aparência**
**JavaScript → lógica e comportamento**

Aprender JavaScript permite criar páginas mais interativas e também abre caminho para o desenvolvimento de aplicações completas, utilizando tecnologias tanto de **Front-end** quanto de **Back-end**.
